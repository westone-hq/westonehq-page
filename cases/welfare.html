돌봄 일지

돌봄 일지를 쓰고 다음 근무자에게 인수인계하는 앱입니다.

자료를 정리하고 있습니다. 내용이 더 추가됩니다.

기관
원광장애인통합복지관
분야
서버·데이터
형태
API 서버, 데이터베이스

문제

돌봄 일지를 쓰고 인수인계하는 앱에는 일지와 이용자, 담당자 정보를 다룰 백엔드가 필요했습니다.

해결

구조

앱과 웹은 반드시 API 서버를 거칩니다

안드로이드 앱과 웹은 데이터베이스에 직접 붙지 않고 반드시 이 API 서버를 거칩니다. 데이터베이스 접속 정보는 코드에 쓰지 않고 환경변수로만 다룹니다.

개인정보

실제 이용자 정보는 개발에 쓰지 않습니다

개발과 시범 운영은 가상 데이터로만 하고, 실제 이용자 정보는 개발 데이터베이스·테스트·문서 어디에도 넣지 않습니다.

기능

앱 화면을 받치는 서버 기능

앱은 로그인, 일지(홈·오늘의 소식·일지 작성·활동 입력), 달력, 통계(도전적 행동·참여 활동·항목별), 마이페이지(이용자·담당자 관리, 파일 출력)로 이루어져 있습니다. 서버는 이 화면들이 쓰는 기능을 묶음별로 나눴습니다.

  • 인증: 세션, 비밀번호 규칙
  • 일지, 이용자, 담당자
  • 달력, 통계
  • 알림: 읽음 처리

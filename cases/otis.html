OTIS V-Check

전용 장비 대신 설치 기사의 휴대폰으로 승강기 진동·소음을 재고, 규격 리포트를 만들어 메일로 보내는 현장 앱입니다.

기관
OTIS
분야
앱·웹앱
형태
Android 현장 앱 (Flutter)
상태
현장 배포 중

문제

승강기의 진동·소음·속도·거리를 검증하는 측정은 전용 장비로만 해 왔습니다. 현장 설치 기사가 늘 가지고 다니는 휴대폰으로 같은 측정을 하고, 규격에 맞는 리포트까지 현장에서 보낼 수 있어야 했습니다.

해결

측정

휴대폰을 카 바닥에 놓고 잽니다

현장 정보(제번·현장명·층·운전 방향·기종)를 입력하고 측정을 시작합니다. 휴대폰을 뒤집어 카 바닥 중앙에 놓고 운행하면 3축 진동과 소음을 함께 기록하고, 운행이 끝나면 볼륨키를 눌러 측정을 끝냅니다. 입력한 현장 정보는 기기에 남아 다음 측정에 그대로 쓰입니다.

결과

결과 지표를 확인하고 비교합니다

결과 화면에서 소음, X·Y·Z 진동, 최대 속도, 운행 거리를 확인합니다. 다른 측정과 비교하거나, 같은 조건으로 바로 다시 잴 수 있습니다.

리포트

규격 리포트 PDF를 만들어 메일로 보냅니다

측정 결과로 OTIS TUNE 규격의 PDF 리포트를 만들고, 앱에서 바로 메일로 보냅니다. 앞쪽에는 지표와 판정이, 다음 쪽에는 진동·소음 차트가 들어갑니다.

배포

명단 엑셀만 올리면 새 버전이 준비됩니다

관리자가 작업자 명단 엑셀을 올리고 GitHub에서 "새 버전 준비"를 실행하면, 명단 변환부터 검사, 서명한 APK 빌드, 릴리스 초안까지 자동으로 준비됩니다. 운영자 PC에는 개발 도구가 필요 없고, 게시는 담당자가 첨부 파일을 확인한 뒤 직접 합니다.

어떻게 만들었나

앱
Flutter로 화면을 만들고, 센서와 소음 수집은 Kotlin 네이티브 코드로 처리합니다
신호 처리
필터와 재표본 등 처리 순서를 SciPy로 만든 정본과 대조해 맞췄습니다
구조
domain·adapter·service·ui 층으로 나누고, 층 사이 규칙을 테스트로 고정했습니다
릴리스
GitHub Actions로 서명한 APK와 릴리스 초안을 만듭니다

설계 문서

새 창에서 크게 보기

유즈케이스 1장, 액티비티 18장, 시퀀스 13장으로 이루어져 있습니다.

검증 방식

SciPy로 만든 기준값을 테스트 자료로 두고, 앱의 신호 처리 결과와 대조했습니다.

기존 측정 장비와 같은 운행을 함께 측정해 진동과 소음 곡선을 비교했습니다.
